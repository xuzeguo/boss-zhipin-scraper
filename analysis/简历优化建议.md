**9 份 JD 原文技术词命中：** HTML/CSS(9) > JavaScript(7) > **TypeScript(5)** > **性能优化(5)** > **后端能力(5)** > React(4) > Vue(3) > Webpack/Vite(3)

**核心发现：**
- **React 和 Vue 都要会**，不能只会一个（React 11 次 vs Vue 10 次， JD 里 React 略占优）
- **TypeScript 已是隐性硬要求**（JD 命中 5/9，中高端岗位几乎标配）
- **性能优化 / 工程化（Vite/Webpack）是中高级分水岭**
- **懂一点后端（Node/Go/Java）是明显加分项**，全栈岗位 5 条
- 移动端 H5 / 小程序 / React Native 是差异化方向

## 三、简历改进建议（对照市场）

### 1. 技术栈关键词补齐（优先级从高到低）
- **必备**：JavaScript(ES6+)、HTML5、CSS3、React、Vue、TypeScript
- **强加分**：Webpack/Vite 工程化、性能优化实操、Git、浏览器调试/跨域/兼容
- **差异化**：Node.js 或一门后端、微信小程序 / React Native、ECharts 数据可视化、AI 辅助开发（JD 已出现）

### 2. 项目经历改写方向（用 STAR + 量化）
- 不要写"负责前端开发"，要写"用 React + TS 重构 XX 模块，**首屏加载从 3s 降到 1.2s**"
- 突出**性能优化**：首屏、懒加载、打包体积、缓存策略——这是 5/9 份 JD 明确提到的
- 突出**工程化**：从 0 搭 Vite/Webpack、组件库、CI/CD、代码规范
- 突出**全栈/联调**：独立设计接口、Node BFF 层、跨端适配
- 每个项目至少带 2-3 个可量化指标（性能、效率、规模、转化率）

### 3. 经历定位
- 你若 3-5 年经验：简历定位「中高级前端」，重点展示独立负责模块 + 性能/工程化能力
- 若目标 25K+：需要体现架构设计、技术选型、带人或跨端经验

### 4. 高频福利关键词（谈薪参考）
五险一金(36)、带薪年假(29)、节日福利(27)、年终奖(23)、补充医疗(18)、定期体检(18)、团建(18)、股票期权(13)
